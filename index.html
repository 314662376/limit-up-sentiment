涨停情绪指数 实时计算，每分钟刷新；横轴固定为完整交易日 09:30–15:00

· 指标构成：昨日封板率 = 同花顺涨停池家数 ÷ (涨停池 + 炸板池)，取最近一个有数据交易日的收盘值；涨停表现 = 同花顺 883900「昨日涨停表现」当日实时涨跌幅；上证 = 上证指数当日实时涨跌幅。三者均来自同花顺公开行情接口。
· 历史数据（5 日图）由仓库内 data/*.json 提供，交易日盘中由 GitHub Actions 每分钟采集一次并自动提交；当日曲线则由浏览器实时直连计算，因此比存档更及时。图例中「基准」即该条曲线所用的「昨日封板率」所属交易日（曲线日的前一交易日），与顶部当日所用的基准同义。同花顺不提供按日期的历史分时，故 5 日图只能由 Actions 逐交易日累积，上线初期不足 5 条属正常。
· y 轴固定在 0.95 ~ 1.05（0.025 一档：0.95 / 0.975 / 1.00 / 1.025 / 1.05），不随数据自动放大缩小；红色虚线为 1.000 中性基准。当日分时图的横轴同样固定为完整交易日 09:30–15:00，盘中不随实时数据延长。若有数据点超出 0.95~1.05，会被裁掉并在图下方提示。
