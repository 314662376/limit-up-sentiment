· 取数口径：涨停池 / 炸板池家数取同花顺 dataapi/limit_up，取「当前曲线所属交易日的前一个交易日」收盘值（页面直连该接口现算，接口不通时回落到仓库 data/*.json 存档）；883900=昨日涨停表现、883918=昨日炸板股、1A0001=上证指数，均为当前交易日的分时涨跌幅。
· 两个封板率：总封板率 = 涨停家数 ÷ (涨停家数 + 炸板家数)（指数①用）；非一字板封板率 = 非一字板涨停家数 ÷ (非一字板涨停家数 + 炸板家数)，其中 非一字板涨停家数 = 涨停家数 − 一字板家数（指数②用，「一字板」按同花顺涨停池的 limit_up_type 判定）。炸板率 = 100% − 非一字板封板率。
· y 轴均固定不缩放：①固定在 0.925 ~ 1.075，灰色虚线为 1.000 中性基准；②固定在 −200 ~ 300，灰色虚线为 0。当日分时图的横轴同样固定为完整交易日 09:30–15:00，盘中不随实时数据延长。若有数据点超出固定区间，会被裁掉并在图下方提示。
· 阈值警示（1 日图）：①低于 0.95 的线段标红、高于 1.05 的标绿；②低于 −100 标红、高于 200 标绿。阈值处以虚线标出，越界区域另加淡色背景带；5 日图因靠颜色区分交易日，只保留背景带与阈值虚线，不改线色。
· 5 日图由仓库内 data/*.json 提供，每个交易日收盘后由 GitHub Actions 抓取当日完整分时（241 个点）一次写齐。当日曲线由浏览器直连现算，因此始终比存档更及时。同花顺不提供按日期的历史分时，故 5 日图只能逐交易日累积：①依赖 883900 + 上证 分时（已可回溯）；②还需 883918 分时（无法回溯），因此②的历史曲线从上线当日开始累积。
